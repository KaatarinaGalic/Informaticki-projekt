# Spotify Dataset Analysis (1921–2020)

## Opis projekta

Ovaj projekt temelji se na Spotify datasetu koji sadrži audio značajke pjesama objavljenih između 1921. i 2020. godine. Cilj projekta je analiza glazbenih trendova kroz vrijeme te istraživanje odnosa između različitih audio karakteristika i popularnosti pjesama.

Dataset uključuje više od 160.000 pjesama i njihove audio značajke dobivene putem Spotify API-ja.

## Dataset

Spotify Dataset (1921–2020):  
https://data.world/babarory/spotify-dataset-1921-2020

---

# Ciljevi projekta

- Analiza glazbenih trendova kroz godine
- Istraživanje promjena u audio značajkama pjesama
- Analiza popularnosti pjesama kroz različita desetljeća
- Vizualizacija odnosa između audio značajki
- Primjena eksplorativne analize podataka (EDA)
- Primjena PCA metode za smanjenje dimenzionalnosti podataka

# Audio značajke u datasetu

Dataset sadrži velik broj audio značajki pjesama, uključujući:

- acousticness

- energy
- tempo
- loudness
- valence
- speechiness
- instrumentalness
- liveness
- popularity
- year

- naziv pjesme

- veću energiju
- veću glasnoću

Također je uočena povezanost između popularnosti pjesama i audio značajki poput energije i loudness vrijednosti.
